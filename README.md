## Learning Path

A practical progression through these cybersecurity labs is:

1. Begin with **repository and web reconnaissance**.
2. Study **hidden Git paths and exposed files**.
3. Practice controlled **file-transfer** techniques.
4. Learn the security concepts behind **reverse shells**.
5. Analyze **backdoor source code** and compiled backdoor behavior in isolated labs.
6. Study **cron and scheduled-task security**.
7. Finish with the **Red Line to Root** challenges to connect reconnaissance, misconfiguration, and privilege escalation.

## How to Use the Labs

Use these exercises only in authorized lab environments.

Recommended workflow:

1. Read the lab objective before beginning.
2. Identify the relevant attack surface or security weakness.
3. Perform controlled reconnaissance.
4. Document files, services, source-code clues, permissions, and configuration findings.
5. Investigate the challenge within the provided environment.
6. Record the security impact and potential remediation.
7. For defensive learning, consider how monitoring, access controls, file integrity checks, and secure configuration could prevent the observed issue.

For reverse-shell and backdoor-focused exercises, work only with intentionally vulnerable lab systems. Do not deploy backdoors or remote-access mechanisms against systems without explicit authorization.
